# Akash Portfolio

One-page portfolio website tailored for software engineering recruiter outreach.

## Live Link
- https://muvvalaakashsiddhardha.github.io/akash-portfolio/

## About
This portfolio presents my software engineering profile with:
- Professional summary
- Core technical and delivery skills
- Project highlights
- Engineering-fit section for recruiters
- Direct contact links and resume access

## Tech Stack
- HTML5
- CSS3

## Project Structure
- `index.html` - Main portfolio page
- `styles.css` - Styling
- `resume.pdf` - Resume file linked from portfolio
- `CNAME` - Custom domain setting (optional for GitHub Pages)

## Run Locally
Open `index.html` directly in your browser.

## Deployment (GitHub Pages)
1. Push the repository to GitHub.
2. Go to `Settings > Pages`.
3. Select `Deploy from a branch`.
4. Choose `main` and `/(root)`.
5. Save and wait for deployment.
